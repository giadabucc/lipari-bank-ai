# AI Code Review — Giorno 1

Una riga per rilievo. Stato: **corretto** / **non corretto** (con la ragione) / **ok** (verificato, niente da fare).

## 1. pyproject.toml — dipendenze non usate

- **ok** — Ogni dipendenza ha un uso: `fastapi`, `pydantic-settings` (src), `uvicorn[standard]` (l'extra porta `watchfiles`, che serve a `--reload`), `httpx` e `pytest-asyncio` (il test asincrono di `/health`), `ruff`, `mypy`, `pytest` (scripts/check.py).
- **corretto** — `description = "Add your description here"`, rimasto dal template di `uv init`: sostituito con la descrizione vera.
- **non corretto** — In `[tool.mypy]`, `disallow_untyped_defs` e `warn_return_any` sono già compresi in `strict = true`, quindi sono ridondanti. Li lascio: dicono a chi legge le due regole che contano di più, senza che debba conoscere l'elenco di `--strict`.

## 2. Il segreto

- **ok** — Nel codice di `src/` non c'è nessuna chiave: `JWT_SECRET` e le chiavi dei modelli si leggono dall'ambiente o dal `.env`, che sta nel `.gitignore` (verificato con `git status`). In `.env.example` le righe dei segreti sono vuote.
- **ok** — `/health` espone le chiavi solo come `true` / `false`; un test controlla che nella risposta non compaia né il valore né un suo pezzo.
- **non corretto** — `conftest.py` contiene una stringa fissa per `JWT_SECRET`. È un valore dei test, non un segreto: non firma niente di reale, e `setdefault` fa vincere l'ambiente se ne ha già uno. Toglierlo farebbe fallire i test su ogni macchina senza `.env`, CI compresa.

## 3. I tipi

- **ok** — `uv run mypy src scripts` in strict: nessun problema in 5 file; nessun `# type: ignore` e nessun `Any` esplicito.
- **non corretto** — I parametri dei test (`tmp_path`, `monkeypatch`, `capsys`) non sono annotati: è voluto, `pyproject.toml` disattiva ANN001/ANN201 su `tests/*`. La regola di mypy per i test arriva con il Giorno 7.

## 4. Il secondo sviluppatore che clona

- **corretto** — Il README era vuoto (template di `uv init`): ora copre l'installazione, la configurazione, l'avvio e i controlli.
- **corretto** — Senza `.env` l'app non parte: il README dice di copiare `.env.example` e di generare `JWT_SECRET`, con il comando per Windows e quello per Linux/Mac; al posto di `curl` dà i link da aprire nel browser, perché in Windows PowerShell 5.1 `curl` è un alias di `Invoke-WebRequest`.
- **corretto** — `uv sync` senza `--locked` può risolvere versioni diverse da `uv.lock`: il README e la CI usano `uv sync --locked`.
- **ok** — Il collega non deve installare Python a mano: uv legge `.python-version` e scarica la 3.12.
